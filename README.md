# Spam Email Classifier

This is a Machine Learning project that classifies SMS messages as Spam or Ham (Not Spam).

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Dataset
spam.csv

## Model
The model is trained using TF-IDF Vectorizer and a Machine Learning classifier.

## Accuracy
97%

## Files
- spam_email_classifier.ipynb
- spam_model.pkl
- spam.csv
